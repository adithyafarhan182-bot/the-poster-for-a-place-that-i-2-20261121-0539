SOLMARA — a travel poster for a place that isn't there. On Solmara the sun sets twice a day: a small pale sun first, then a great amber one sinking into a mirror lagoon, watched over by the Sunspire tower on the cliff. Two sunsets a day — sail at dusk.

## Run it

```sh
node main.ts
```

The program draws the poster procedurally — sky gradient, two suns, lagoon with sun-roads, cliff headland, the Sunspire tower, and hand-built 5×7 bitmap type — and writes `/output/entry.png` (768×1024 PNG, pure Node 22 stdlib, no network, no assets).
